# Childhood Trauma Simulator

An interactive Phaser browser-game prototype about rescuing Artax from the Swamp of Darkness and changing a painful childhood ending.

Repeated pulls fight the swamp in time with the Chapter 1 cover track. Survive the struggle, build enough effort, and reach the childhood-healing ending.

## Run

```powershell
pnpm install
pnpm dev
```

Open the local URL shown by Vite. Repeatedly press Space or click the center button to pull Artax from the bog. Audio begins after the first interaction because browsers require user input before playback.

## Build and test

```powershell
pnpm test
pnpm build
```

Live demo: https://trauma.ottobohn.com/
